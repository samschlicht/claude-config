# PR Description Phase

Write a pull request description capturing what was built.

## Instructions

Create or overwrite `pr-description.md` in the project root with the following
sections:

- **Description**: what changed and why — written for a code reviewer, not a
  summary of tasks completed
- **Modified components**: list of files or modules that were changed, grouped
  logically if there are many
- **Tests**: tests added or updated; if none, say so explicitly

Base the content on the plan.md, the implemented code, and the git diff since
the branch diverged from the base branch. Do not pad — if a section is short,
leave it short.
